# Personal Gesture Manager

* ผู้พัฒนา: Peem Narkkhwan
* ติดต่อ: sharetoyouaccess@gmail.com
* เวอร์ชัน: 2026.10.5
* รองรับ: NVDA 2026.1 ขึ้นไป (ทดสอบล่าสุดกับ NVDA 2026.2)

## 1. บทนำ

Personal Gesture Manager เป็นส่วนเสริมของ NVDA ที่รวบรวมคำสั่งและปุ่มลัดของ NVDA และของส่วนเสริมทุกตัวที่ติดตั้งไว้ มาไว้ในหน้าต่างเดียว คำว่า "ปุ่มลัด" ในคู่มือนี้ครอบคลุมทั้งปุ่มลัดบนแป้นพิมพ์ ปุ่มบนเครื่องแสดงผลอักษรเบรลล์ และท่าทางบนหน้าจอสัมผัส

ส่วนเสริมนี้ช่วยให้ผู้ใช้สามารถ

* ดูคำสั่งทั้งหมดของส่วนเสริมแต่ละตัว พร้อมปุ่มลัดที่กำหนดไว้
* ตรวจหาปุ่มลัดที่ถูกกำหนดให้มากกว่าหนึ่งคำสั่ง และแก้ไขได้ทันที
* เพิ่ม เปลี่ยน ลบ หรือคืนค่าปุ่มลัด โดยระบบจะสำรองข้อมูลให้อัตโนมัติก่อนการแก้ไขทุกครั้ง
* ตรวจสอบว่าใช้คำสั่งใดบ่อย และปุ่มลัดใดไม่เคยใช้
* ทดสอบปุ่มลัดใดก็ได้เพื่อดูว่าทำหน้าที่อะไร ก่อนกำหนดใช้งาน
* อ่านวิธีใช้ฉบับย่อของส่วนเสริมแต่ละตัว หรือเปิดคู่มือฉบับเต็ม รวมถึงคู่มือของ NVDA

ข้อมูลที่แสดงตรงกับการตั้งค่า NVDA ของผู้ใช้เสมอ ทั้ง NVDA แบบติดตั้งและแบบพกพา

## 2. เริ่มต้นใช้งาน

### การเปิดส่วนเสริม

กด NVDA+G หรือเปิดเมนู NVDA แล้วเลือก เครื่องมือ ตามด้วย Personal Gesture Manager

### การแก้ปุ่มลัดซ้ำ

1. กด Ctrl+Tab เพื่อไปที่แท็บ "ปุ่มลัดซ้ำ" แล้วกด Tab เพื่อไปที่รายการ
2. กด Enter ที่ปุ่มลัดที่ต้องการ เลือกคำสั่งหนึ่งจากคำสั่งที่ใช้ปุ่มลัดนี้ร่วมกัน แล้วเลือกว่าจะเปลี่ยนปุ่มลัดของคำสั่งนั้น หรือนำปุ่มลัดออกจากคำสั่งนั้น
3. NVDA จะแจ้งผลการดำเนินการและจำนวนปุ่มลัดซ้ำที่เหลืออยู่ จากนั้นจึงดำเนินการกับรายการถัดไปได้

### การกำหนดปุ่มลัดให้คำสั่ง

1. ในแท็บ "คำสั่งของส่วนเสริม" ตั้งช่อง "ตัวกรอง" (Alt+F) เป็น "คำสั่งที่ไม่มีปุ่มลัด" กด Tab เพื่อไปที่รายการ แล้วพิมพ์ตัวอักษรแรกของชื่อคำสั่ง
2. กด Enter ที่คำสั่ง แล้วเลือก "เพิ่มปุ่มลัด"
3. กดปุ่มลัดใหม่ NVDA จะแจ้งว่าปุ่มลัดนี้ว่างหรือมีคำสั่งใดใช้อยู่ แล้วจึงถามว่าจะใช้ปุ่มลัดนี้กับรูปแบบแป้นพิมพ์ใด

### การเปลี่ยนหรือลบปุ่มลัด

กด Enter ที่คำสั่ง ในหน้าต่างที่เปิดขึ้น ให้กด Enter ที่ปุ่มลัดเพื่อเปลี่ยน หรือกด Delete เพื่อลบ

### การย้อนการแก้ไข

กด Alt+B (ข้อมูลสำรอง) เลือก "ย้อนการแก้ไขล่าสุด" แล้วตอบ "ใช่"

### การค้นหาปุ่มลัดที่ไม่ได้ใช้

ในแท็บ "สถิติการใช้งาน" ตั้งช่อง "ตัวกรอง" เป็น "คำสั่งที่มีปุ่มลัดแต่ไม่ได้ใช้" และตั้งช่อง "ช่วงเวลา" เป็น "30 วันล่าสุด" หรือ "ตั้งแต่เริ่มบันทึก" ระบบเริ่มบันทึกการใช้งานตั้งแต่วันที่ติดตั้งส่วนเสริม จึงควรใช้งานไปสักระยะหนึ่งก่อนพิจารณาเปลี่ยนแปลงปุ่มลัด

## 3. การใช้งานหน้าต่าง

### การเปิดและปิดหน้าต่าง

เปิดส่วนเสริมได้ 2 วิธี ดังนี้

* กด NVDA+G ผู้ใช้สามารถเปลี่ยนปุ่มลัดนี้ได้เช่นเดียวกับปุ่มลัดอื่น โดยเลือกคำสั่ง "เปิด Personal Gesture Manager" ในแท็บ "คำสั่งของส่วนเสริม"
* เปิดเมนู NVDA แล้วเลือก เครื่องมือ ตามด้วย Personal Gesture Manager

คำสั่ง "เปิดแท็บทดสอบปุ่มลัดของ Personal Gesture Manager" ใช้เปิดแท็บ "ทดสอบปุ่มลัด" โดยตรง คำสั่งนี้ไม่มีปุ่มลัดตั้งไว้ล่วงหน้า ผู้ใช้สามารถกำหนดเองได้

หากหน้าต่างเปิดอยู่แล้ว การกด NVDA+G จะนำหน้าต่างกลับมาด้านหน้า ณ ตำแหน่งเดิมที่ใช้งานอยู่ และ NVDA จะแจ้งว่า "Personal Gesture Manager เปิดอยู่แล้ว"

กด Escape หรือ Alt+C เพื่อปิดหน้าต่าง

### แท็บต่าง ๆ

หน้าต่างประกอบด้วย 5 แท็บ ได้แก่

1. คำสั่งของส่วนเสริม
2. ปุ่มลัดซ้ำ
3. สถิติการใช้งาน
4. ทดสอบปุ่มลัด
5. คู่มือ NVDA และส่วนเสริม

กด Ctrl+Tab หรือ Ctrl+Shift+Tab เพื่อไปยังแท็บถัดไปหรือแท็บก่อนหน้า หรือกด Ctrl+1 ถึง Ctrl+5 เพื่อไปยังแท็บนั้นโดยตรง NVDA จะแจ้งชื่อแท็บ แล้วจึงอ่านช่องแรกของแท็บ

เมื่อไปที่แท็บ "ปุ่มลัดซ้ำ" NVDA จะแจ้งจำนวนปุ่มลัดที่ซ้ำกันระหว่างส่วนเสริม เช่น "พบปุ่มลัดซ้ำระหว่างส่วนเสริม 3 รายการ" หากไม่มีปุ่มลัดซ้ำ ระบบจะไม่แจ้งใด ๆ

### ปุ่มลัดภายในหน้าต่าง

ปุ่ม Alt ต่อไปนี้ใช้ได้ทั้งในภาษาไทยและภาษาอังกฤษ และ NVDA จะแจ้งปุ่ม Alt ของแต่ละช่อง ยกเว้นในรายการ

* ทุกแท็บ: Alt+C ปิดหน้าต่าง
* คำสั่งของส่วนเสริม: Alt+A ส่วนเสริม, Alt+F ตัวกรอง, Alt+O รายการคำสั่ง, Alt+S ปรับปุ่มลัดของคำสั่งนี้, Alt+B ข้อมูลสำรอง
* ปุ่มลัดซ้ำ: Alt+F ตัวกรอง, Alt+I แสดงปุ่มลัดที่ซ้ำกันระหว่างคำสั่งของ NVDA เองด้วย, Alt+S ปุ่มลัดที่ใช้ร่วมกัน
* สถิติการใช้งาน: Alt+P ช่วงเวลา, Alt+A ส่วนเสริม, Alt+F ตัวกรอง, Alt+U คำสั่งตามการใช้งาน, Alt+M สรุป, Alt+D ลบสถิติทั้งหมด
* ทดสอบปุ่มลัด: Alt+S เริ่มทดสอบปุ่มลัด, Alt+R รายการทดสอบปุ่มลัด
* คู่มือ NVDA และส่วนเสริม: Alt+A ส่วนเสริมและ NVDA, Alt+Q วิธีใช้ฉบับย่อ, Alt+G เปิดคู่มือฉบับเต็ม

การใช้งานในรายการ

* พิมพ์ตัวอักษรแรกของชื่อเพื่อไปยังรายการนั้น
* กด Enter หรือปุ่ม Applications (Shift+F10) เพื่อดูสิ่งที่ทำได้กับรายการที่เลือก
* ในรายการคำสั่งและรายการปุ่มลัดซ้ำ กด Delete เพื่อลบปุ่มลัด
* หากรายการว่าง NVDA จะแจ้งเหตุผล เช่น "ไม่มีปุ่มลัดที่ซ้ำกัน"

กด F1 ที่ตำแหน่งใดก็ได้ในหน้าต่าง เพื่อเปิดคู่มือนี้ในหัวข้อของแท็บที่ใช้งานอยู่

### ภาษาของหน้าต่าง

หน้าต่างจะแสดงตามภาษาของ NVDA หากมีคำแปล มิฉะนั้นจะแสดงเป็นภาษาอังกฤษ กด Ctrl+T เพื่อสลับระหว่างภาษาไทยกับภาษาอังกฤษ NVDA จะแจ้งการเปลี่ยนภาษาเป็นทั้งสองภาษา เพื่อให้ผู้ใช้ทราบวิธีเปลี่ยนกลับเสมอ โดยตำแหน่งที่ใช้งานอยู่จะไม่เปลี่ยนแปลง ระบบจะจดจำภาษาที่เลือกไว้แม้เริ่ม NVDA ใหม่

ชื่อคำสั่งและชื่อปุ่มลัดมาจาก NVDA จึงแสดงตามภาษาของ NVDA เสมอ

### ข้อมูลเกี่ยวกับระบบ

กด NVDA+T ในหน้าต่างนี้เพื่อฟังข้อมูลโดยสรุป ได้แก่ รุ่นของ NVDA ประเภทการติดตั้ง (แบบติดตั้งหรือแบบพกพา) ชื่อเครื่อง และรุ่นของ Windows

* กด NVDA+T สองครั้งติดกันเพื่อฟังรายละเอียดทั้งหมดทีละบรรทัด ได้แก่ รุ่นและโฟลเดอร์ของ NVDA ตำแหน่งที่บันทึกปุ่มลัดและการตั้งค่า รูปแบบแป้นพิมพ์และภาษาแป้นพิมพ์ จำนวนปุ่มลัดซ้ำและจำนวนส่วนเสริมที่ติดตั้ง รุ่นและ build ของ Windows และโปรแกรมที่ใช้แสดงคำสั่ง
* กด NVDA+T สามครั้งติดกันเพื่อคัดลอกรายละเอียดเหล่านี้ เช่น เพื่อแนบไปกับข้อความขอความช่วยเหลือ ข้อมูลดังกล่าวมีชื่อเครื่องและชื่อผู้ใช้ Windows จึงควรตรวจสอบก่อนเผยแพร่ในที่สาธารณะ

ในหน้าต่างอื่น NVDA+T ยังคงทำงานตามปกติ

## 4. แท็บคำสั่งของส่วนเสริม {#commands}

ใช้สำหรับตรวจสอบและแก้ไขปุ่มลัด

### 4.1 การเลือกคำสั่งที่จะแสดง

* ส่วนเสริม: เลือกแหล่งที่มาของคำสั่ง
    * ส่วนเสริมทั้งหมด (ค่าเริ่มต้น): คำสั่งของส่วนเสริมทุกตัว ไม่รวมคำสั่งของ NVDA
    * NVDA: เฉพาะคำสั่งของ NVDA
    * ชื่อส่วนเสริม: เฉพาะคำสั่งของส่วนเสริมนั้น
    * ส่วนเสริมทั้งหมดและ NVDA: ทุกคำสั่ง
* ตัวกรอง: เลือกประเภทของคำสั่งที่จะแสดง
    * คำสั่งที่มีปุ่มลัด (ค่าเริ่มต้น): คำสั่งที่เรียกใช้ด้วยปุ่มลัดได้แล้ว
    * คำสั่งที่มีปุ่มลัดมากกว่า 1 ปุ่ม: ใช้ตรวจสอบว่ายังจำเป็นต้องมีปุ่มลัดทุกปุ่มหรือไม่
    * คำสั่งที่ไม่มีปุ่มลัด: คำสั่งที่สามารถกำหนดปุ่มลัดเพิ่มได้
    * ทุกคำสั่ง

### 4.2 การอ่านรายการ

แต่ละแถวแสดงชื่อคำสั่งและปุ่มลัด คำสั่งที่ไม่มีปุ่มลัดจะแสดงว่า "ไม่มีปุ่มลัด" หากปุ่มลัดของคำสั่งนั้นมีคำสั่งอื่นใช้อยู่ด้วย แถวนั้นจะแสดงว่า "ปุ่มลัดซ้ำกับคำสั่งอื่น" และเมื่อเลือกแสดงส่วนเสริมทั้งหมด ท้ายแถวจะมีชื่อส่วนเสริมกำกับไว้

### 4.3 การปรับปุ่มลัดของคำสั่ง

กด Enter ที่คำสั่ง หรือเลือก "ปรับปุ่มลัดของคำสั่งนี้" (Alt+S) หน้าต่างที่เปิดขึ้นประกอบด้วย

* ปุ่มลัด: รายการปุ่มลัดของคำสั่ง กด Enter ที่ปุ่มลัดเพื่อเปลี่ยน หรือกด Delete เพื่อลบ
* เพิ่มปุ่มลัด
* คืนค่าปุ่มลัดเริ่มต้นของคำสั่งนี้
* คืนค่าปุ่มลัดเริ่มต้นทุกคำสั่งของส่วนเสริม
* ปิดหน้าต่าง

### 4.4 การเพิ่มหรือเปลี่ยนปุ่มลัด

"เพิ่มปุ่มลัด" จะเพิ่มปุ่มลัดใหม่โดยยังคงปุ่มลัดเดิมไว้ หากต้องการแทนที่ปุ่มลัดเดิม ให้กด Enter ที่ปุ่มลัดนั้นในรายการ "ปุ่มลัด"

1. กดปุ่มลัดใหม่
2. หากเป็นปุ่มที่ใช้พิมพ์ตามปกติ เช่น ตัวอักษร ตัวเลข Space, Enter หรือปุ่มลูกศร ระบบจะขอให้ยืนยันก่อน เนื่องจากปุ่มนั้นจะไม่สามารถใช้พิมพ์ได้อีก ตอบ "ไม่" เพื่อกดปุ่มอื่นแทน
3. NVDA จะแจ้งว่าปุ่มลัดนี้ว่าง หรือมีคำสั่งใดใช้อยู่แล้ว
4. สำหรับปุ่มลัดบนแป้นพิมพ์ ให้เลือกรูปแบบแป้นพิมพ์ที่จะใช้ ได้แก่ ทุกรูปแบบแป้นพิมพ์ เฉพาะเดสก์ท็อป หรือเฉพาะแล็ปท็อป
5. หากปุ่มลัดนี้มีคำสั่งอื่นใช้อยู่แล้ว ให้เลือกตัวเลือกใดตัวเลือกหนึ่งต่อไปนี้
    * ย้ายมาที่คำสั่งนี้: นำปุ่มลัดออกจากคำสั่งเดิม แล้วกำหนดให้คำสั่งนี้
    * คงไว้ทั้งสองคำสั่ง: ทั้งสองคำสั่งใช้ปุ่มลัดเดียวกัน โดย NVDA จะแจ้งว่าคำสั่งใดจะทำงานจริง
    * กดปุ่มอื่น: เลือกปุ่มลัดอื่นแทน
    * ยกเลิก: ไม่มีการเปลี่ยนแปลงใด ๆ

    หากคำสั่งเดิมเป็นคำสั่งของ NVDA ระบบจะแสดงคำเตือนเพิ่มเติม

เมื่อแทนที่ปุ่มลัด ระบบจะลบปุ่มลัดเดิมหลังจากยืนยันแล้วว่าปุ่มลัดใหม่ใช้งานได้เท่านั้น หากการแก้ไขไม่สำเร็จ NVDA จะแจ้งให้ทราบ และระบบจะคงค่าเดิมไว้ทั้งหมด

### 4.5 การลบปุ่มลัด

เลือกคำสั่ง แล้วกด Delete หากคำสั่งมีปุ่มลัดมากกว่าหนึ่งปุ่ม ให้เลือกปุ่มลัดที่ต้องการลบ ระบบจะขอให้ยืนยันก่อนลบทุกครั้ง

### 4.6 การคืนค่าปุ่มลัดเริ่มต้น

ในหน้าต่างที่เปิดขึ้นเมื่อกด Enter ที่คำสั่ง

* คืนค่าปุ่มลัดเริ่มต้นของคำสั่งนี้: ยกเลิกการเปลี่ยนแปลงทั้งหมดของคำสั่งนี้ จากนั้น NVDA จะแจ้งปุ่มลัดปัจจุบันของคำสั่ง
* คืนค่าปุ่มลัดเริ่มต้นทุกคำสั่งของส่วนเสริม: ยกเลิกการเปลี่ยนแปลงทั้งหมดของทุกคำสั่งในส่วนเสริมเดียวกัน หรือของ NVDA โดยระบบจะขอให้ยืนยันก่อน

### 4.7 ข้อมูลสำรองและการย้อนการแก้ไข

ระบบจะสำรองปุ่มลัดโดยอัตโนมัติก่อนการแก้ไขทุกครั้ง และเก็บข้อมูลสำรองไว้ 10 ชุดล่าสุด

เลือก "ข้อมูลสำรอง" (Alt+B) เพื่อดูรายการ

* "ย้อนการแก้ไขล่าสุด" จะอยู่ลำดับแรกเสมอ พร้อมระบุการแก้ไขที่จะย้อนกลับ
* รายการอื่นแสดงวันที่ เวลา และการแก้ไขที่ตามมา เช่น "2026-10-03 14:22:05 ก่อนเพิ่ม NVDA+Shift+X ให้ อ่านเวลา"

การกู้คืนข้อมูลสำรองจะแทนที่ปุ่มลัดที่ผู้ใช้กำหนดเองทั้งหมด รวมถึงปุ่มลัดที่แก้ไขในหน้าต่างคำสั่งของ NVDA เอง ระบบจะสำรองปุ่มลัดปัจจุบันไว้ก่อนทุกครั้ง จึงสามารถย้อนการกู้คืนได้

## 5. แท็บปุ่มลัดซ้ำ {#conflicts}

แสดงปุ่มลัดที่ถูกกำหนดให้มากกว่าหนึ่งคำสั่ง

ตัวกรอง

* ปุ่มลัดซ้ำ (ค่าเริ่มต้น): มีเพียงคำสั่งเดียวที่ทำงานได้ และไม่สามารถทราบได้ว่าเป็นคำสั่งใด ควรแก้ไขรายการประเภทนี้
* มีคำสั่งหนึ่งชนะ: มีคำสั่งหนึ่งที่ได้รับลำดับความสำคัญเหนือคำสั่งอื่นเสมอ คำสั่งที่ระบุว่า "(ทำงานอยู่)" คือคำสั่งที่จะทำงาน
* ขึ้นกับตำแหน่งโฟกัส: คำสั่งที่ทำงานขึ้นอยู่กับตำแหน่งที่ใช้งานอยู่ เช่น ในเอกสาร หรือในช่องแก้ไขข้อความ

โดยค่าเริ่มต้น รายการจะแสดงเฉพาะปุ่มลัดที่เกี่ยวข้องกับส่วนเสริม หากต้องการแสดงปุ่มลัดที่ซ้ำกันระหว่างคำสั่งของ NVDA เองด้วย ให้เลือก "แสดงปุ่มลัดที่ซ้ำกันระหว่างคำสั่งของ NVDA เองด้วย"

แต่ละแถวแสดงปุ่มลัด รูปแบบแป้นพิมพ์ และจำนวนคำสั่งที่ใช้ปุ่มลัดร่วมกัน เช่น "NVDA+F12, ทุกรูปแบบแป้นพิมพ์, 2 คำสั่ง"

กด Enter ที่แถว แล้วเลือกคำสั่งหนึ่งจากคำสั่งที่ใช้ปุ่มลัดร่วมกัน จากนั้นเลือกการดำเนินการ

* เปลี่ยนปุ่มลัดของคำสั่งนี้: กดปุ่มลัดใหม่ได้ทันที
* เอาปุ่มลัดออกจากคำสั่งนี้: หากมีเพียงสองคำสั่ง อีกคำสั่งหนึ่งจะยังคงใช้ปุ่มลัดนี้ต่อไป
* ให้คำสั่งนี้ใช้ปุ่มลัดเพียงคำสั่งเดียว: มีให้เลือกเมื่อมีตั้งแต่สามคำสั่งขึ้นไป ระบบจะนำปุ่มลัดออกจากคำสั่งอื่นทั้งหมด

กด Delete ที่แถว เพื่อนำปุ่มลัดออกจากคำสั่งที่เลือก

หลังการแก้ไขแต่ละครั้ง โฟกัสจะยังอยู่ในรายการ และ NVDA จะแจ้งผลการดำเนินการพร้อมจำนวนปุ่มลัดซ้ำที่เหลืออยู่

## 6. แท็บสถิติการใช้งาน {#statistics}

แสดงว่าผู้ใช้ใช้คำสั่งใดและบ่อยเพียงใด

* ช่วงเวลา: การเปิด NVDA ครั้งนี้ วันนี้ 7 วันล่าสุด 30 วันล่าสุด หรือตั้งแต่เริ่มบันทึก
* ส่วนเสริม: ตัวเลือกเช่นเดียวกับแท็บ "คำสั่งของส่วนเสริม"
* ตัวกรอง:
    * คำสั่งที่ใช้บ่อยที่สุด: คำสั่งเหล่านี้ควรมีปุ่มลัดที่กดได้สะดวก
    * คำสั่งที่ใช้น้อยที่สุด: คำสั่งที่มีปุ่มลัดและถูกใช้ในช่วงเวลาที่เลือก เรียงจากที่ใช้น้อยที่สุด
    * คำสั่งที่มีปุ่มลัดแต่ไม่ได้ใช้: ปุ่มลัดของคำสั่งเหล่านี้สามารถนำไปกำหนดให้คำสั่งอื่นได้
* คำสั่งตามการใช้งาน: แต่ละแถวแสดงชื่อคำสั่ง จำนวนครั้งที่ใช้ ปุ่มลัด และส่วนเสริม กด Enter ที่แถวเพื่อไปยังคำสั่งนั้นในแท็บ "คำสั่งของส่วนเสริม"
* สรุป: ช่วงเวลา ยอดรวม และวันที่เริ่มบันทึก
* ลบสถิติทั้งหมด: ลบข้อมูลการใช้งานที่บันทึกไว้ทั้งหมด แล้วเริ่มบันทึกใหม่ โดยระบบจะขอให้ยืนยันก่อน

โดยค่าเริ่มต้น แท็บนี้จะแสดงข้อมูล 7 วันล่าสุดของส่วนเสริมทั้งหมด เรียงจากคำสั่งที่ใช้บ่อยที่สุด ระบบจะจดจำตัวเลือกที่ผู้ใช้เลือกไว้

การกดปุ่มลัดแต่ละครั้งนับเป็นการใช้งานหนึ่งครั้ง

## 7. แท็บทดสอบปุ่มลัด {#tester}

1. เลือก "เริ่มทดสอบปุ่มลัด"
2. กดปุ่มหรือทำท่าทางใดก็ได้ NVDA จะแจ้งว่าปุ่มลัดนั้นว่าง หรือมีคำสั่งและส่วนเสริมใดใช้อยู่ โดยคำสั่งนั้นจะไม่ถูกเรียกใช้งานจริง
3. กดปุ่มลัดอื่นต่อไปเพื่อทดสอบทีละปุ่ม
4. กด Escape เพื่อหยุดทดสอบ สำหรับเครื่องแสดงผลอักษรเบรลล์หรือหน้าจอสัมผัส ให้ทำท่าทางเดิมสองครั้งติดกัน การทดสอบจะหยุดเองเมื่อสลับไปยังหน้าต่างอื่น

"รายการทดสอบปุ่มลัด" จะเก็บผลการทดสอบทั้งหมด โดยผลล่าสุดอยู่ด้านบน จนกว่าจะเริ่ม NVDA ใหม่ ผู้ใช้สามารถอ่านด้วยปุ่มลูกศร หรือเลือกและคัดลอกไปใช้ได้

ผลการทดสอบเป็นของโปรแกรมที่ใช้งานอยู่ก่อนเปิดส่วนเสริม

## 8. แท็บคู่มือ NVDA และส่วนเสริม {#guides}

ช่วยให้ผู้ใช้เรียนรู้วิธีใช้ NVDA และส่วนเสริมแต่ละตัว

1. ส่วนเสริมและ NVDA: แสดง "คู่มือผู้ใช้ NVDA" และ "สรุปคำสั่ง NVDA" ไว้ลำดับแรก ตามด้วยส่วนเสริมทุกตัวที่ติดตั้ง พร้อมสถานะ (กำลังทำงาน ไม่ได้ทำงาน หรือปิดใช้งาน) และคำอธิบายโดยย่อ
2. กด Enter ที่ส่วนเสริม หรือเลือก "วิธีใช้ฉบับย่อ" (Alt+Q) เพื่ออ่านวิธีใช้ฉบับย่อ ซึ่งประกอบด้วย
    * หน้าที่ของส่วนเสริม ตามคำอธิบายของผู้พัฒนา
    * คำสั่งทั้งหมด แยกตามหมวดหมู่ พร้อมปุ่มลัด
    * ปุ่มลัดที่ใช้ร่วมกับคำสั่งอื่น
    * เวอร์ชัน ผู้พัฒนา และสถานะของส่วนเสริม
3. หากต้องการอ่านคู่มือฉบับเต็มของผู้พัฒนา ให้เลือก "เปิดคู่มือฉบับเต็ม" (Alt+G) หากคู่มือมีหลายภาษา ระบบจะให้เลือกภาษาที่ต้องการ
4. กด Enter ที่รายการของ NVDA เพื่อเปิดคู่มือนั้นโดยตรง

วิธีใช้ฉบับย่อจะเปิดในหน้าต่างข้อความของ NVDA ใช้ปุ่มลูกศรเพื่ออ่าน และกด H เพื่อไปยังหัวข้อถัดไป รายการคำสั่งจะแสดงได้เฉพาะส่วนเสริมที่กำลังทำงานอยู่

## 9. ข้อมูลส่วนตัวและการจัดเก็บข้อมูล

* ส่วนเสริมนี้บันทึกเฉพาะจำนวนครั้งที่ใช้แต่ละคำสั่ง และไม่บันทึกข้อความที่ผู้ใช้พิมพ์
* สถิติ การตั้งค่า และข้อมูลสำรอง จัดเก็บไว้ในโฟลเดอร์ "personalGestureManager" ภายในโฟลเดอร์การตั้งค่าของ NVDA
* เมื่อถอนการติดตั้งส่วนเสริม โฟลเดอร์นี้จะถูกลบหลังเริ่ม NVDA ใหม่ ปุ่มลัดที่ผู้ใช้กำหนดไว้จะไม่ได้รับผลกระทบ เนื่องจาก NVDA จัดเก็บไว้ในการตั้งค่าของ NVDA เอง และเมื่ออัปเดตส่วนเสริม ข้อมูลทั้งหมดจะยังคงอยู่

## 10. ข้อจำกัด

* คำสั่งที่ใช้เฉพาะในบางโปรแกรมจะแสดงเฉพาะของโปรแกรมที่ใช้งานอยู่ก่อนเปิดส่วนเสริม
* ไม่สามารถทดสอบปุ่ม Escape ได้ เนื่องจากใช้สำหรับหยุดการทดสอบ
* ไม่สามารถใช้ส่วนเสริมบนหน้าจอปลอดภัย เช่น หน้าจอลงชื่อเข้าใช้ Windows
* คำสั่งบางคำสั่งภายในส่วนเสริมเดียวกันไม่สามารถใช้ปุ่มลัดร่วมกันได้ ในกรณีนี้ การกำหนดปุ่มลัดให้อีกคำสั่งหนึ่งจะเป็นการย้ายปุ่มลัดเสมอ และ NVDA จะแจ้งให้ทราบก่อนยืนยัน
